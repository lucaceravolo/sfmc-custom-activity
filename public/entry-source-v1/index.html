External API Entry Source

Associa una Data Extension sendable esistente alla sorgente di ingresso. L'evento verrà inviato successivamente tramite API Marketing Cloud.

Serve l'ObjectID/ID GUID della Data Extension, non la CustomerKey (External Key). La DE deve essere sendable, con ContactKey/SubscriberKey correttamente mappato.
Nota: questo editor non crea un evento dal gestionale e non invia contatti da solo. Salva l'associazione della Data Extension; poi utilizza POST /interaction/v1/events con la Event Definition Key della Journey.
