External API Entry Source v2

Associa una Data Extension sendable esistente alla sorgente di ingresso. L'evento verrà inviato successivamente tramite API Marketing Cloud.

Serve l'ObjectID/ID GUID della Data Extension, non la CustomerKey (External Key). La DE deve essere sendable, con ContactKey/SubscriberKey correttamente mappato.

Condizione di esclusione (facoltativa)

Se il valore del campo indicato coincide con quello configurato, il contatto NON deve entrare nella Journey.

Nome esatto del campo della DE (rispetta maiuscole, minuscole e spazi). Lascia entrambi i campi vuoti per non definire una regola.
Importante: questa schermata salva la regola nella configurazione della Entry Source, ma non la applica da sola. Per impedire davvero l'ingresso, configura in Journey Builder il filtro NomeCampo != ValoreEscluso nello step Filter Contacts, oppure implementa un middleware prima della API Events.
Nota: questo editor non crea un evento dal gestionale e non invia contatti da solo. Salva l'associazione della Data Extension; poi utilizza POST /interaction/v1/events con la Event Definition Key della Journey.
